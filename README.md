# AI Writing Indicator

## Mô tả
Dự án "AI Writing Indicator" thuộc hai bài toán phân loại nhị phân hoặc hồi quy tuyến tính. Mục tiêu chính là huấn luyện một mô hình trí tuệ nhân tạo đánh giá mức độ sử dụng trí tuệ nhân tạo trong tạo sinh văn bản và kết luận văn bản AI hoặc nguời viết. Ngôn ngữ chủ đạo là tiếng Việt.

## Công nghệ sử dụng
Tất cả công nghệ được sử dụng đều là ngôn ngữ Python thuần túy 
- Framework: Streamlit
- Lưu trữ model và dataset: HuggingFace
- Environment: Google Colab
- Model Fine-tune: PhoBert 
- Quản lý phiên bản: Github
