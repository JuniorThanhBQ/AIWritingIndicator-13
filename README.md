> ## English Description Section

The "AI Writing Indicator" project is a binary classification task. The goal is to train a model that can detect the use of Artificial Intelligence (AI) in Vietnamese news articles and classify whether a text was written by AI or a human. The model is designed to work with Vietnamese text. 

The project originally started as a major assignment for an Artificial Intelligence course taught by MSC. H. H. Thiên during semester 252. Later, in October 2026, after discussing the idea with two colleagues, JuniorThanhBQ decided to restart the project and expand its focus to checking whether information generated by AI is true or false.

## III. Application Guide

> [!NOTE]
> 
> Install **uv** and **GNU Make** on your computer before starting. Quick installation commands:
>
> **Windows:**
> ```powershell
> winget install --id astral-sh.uv --exact
> winget install --id GnuWin32.Make --exact
> ```
> Restart your terminal after installation. If `make` is not recognized, add the installed GnuWin32 `bin` folder (usually `C:\Program Files (x86)\GnuWin32\bin`) to your user `Path`, then reopen the terminal.
>
> **macOS:**
> ```bash
> brew install uv make
> export PATH="$(brew --prefix make)/libexec/gnubin:$PATH"
> ```
> Add the `export` line to `~/.zshrc` to keep `make` available in new terminals. Homebrew also provides this command as `gmake`.
>
> **Linux:**
> ```bash
> curl -LsSf https://astral.sh/uv/install.sh | sh
> sudo apt update
> sudo apt install make
> ```
> On other Linux distributions, install GNU Make with your system package manager. Reopen your terminal after installing uv.


### 1. Setup

Open a terminal in the project root folder containing `Makefile` and `pyproject.toml`, then run:

```bash
make install
```

This runs `uv sync --all-packages` to create or update `.venv` and install the project dependencies, including the notebook development group by default. The project requires Python 3.14 or newer; uv can download a compatible interpreter when needed.

### 2. Run the Application

From the project root folder, run:

```bash
make run
```

This runs `uv run streamlit run src/main.py`. uv uses the project environment automatically, so manual activation is not required.

### 3. Access the Application

Open [http://localhost:8501](http://localhost:8501) in your browser. For access from another device on your network, use the **Network URL** printed by Streamlit; its IP address depends on your computer.

### 4. Available Commands

| Make command | uv command | Purpose |
| --- | --- | --- |
| `make` or `make help` | — | Show the available commands. |
| `make install` | `uv sync --all-packages` | Synchronize dependencies for all workspace packages. |
| `make run` | `uv run streamlit run src/main.py` | Start the application. |
| `make upgrade` | `uv sync --upgrade` | Upgrade dependencies within the constraints in `pyproject.toml` and update `uv.lock`. |

Review and test dependency upgrades before committing the updated lockfile. An automated application test suite is not available yet.

### 1. Khởi tạo

Mở terminal tại thư mục gốc của dự án, nơi chứa `Makefile` và `pyproject.toml`, sau đó chạy:

```bash
make install
```

Lệnh này chạy `uv sync --all-packages` để tạo hoặc cập nhật `.venv` và cài các thư viện của dự án, mặc định bao gồm nhóm thư viện phát triển dùng cho notebook. Dự án yêu cầu Python 3.14 trở lên; uv có thể tải phiên bản Python phù hợp khi cần.

### 2. Chạy ứng dụng

Tại thư mục gốc của dự án, chạy:

```bash
make run
```

Lệnh này chạy `uv run streamlit run src/main.py`. uv tự sử dụng môi trường của dự án nên không cần kích hoạt môi trường ảo thủ công.

### 3. Truy cập ứng dụng

Mở [http://localhost:8501](http://localhost:8501) trên trình duyệt. Để truy cập từ thiết bị khác trong cùng mạng, dùng **Network URL** do Streamlit hiển thị; địa chỉ IP phụ thuộc vào máy tính của bạn.

### 4. Các lệnh hỗ trợ

| Lệnh Make | Lệnh uv | Mục đích |
| --- | --- | --- |
| `make` hoặc `make help` | — | Hiển thị các lệnh hỗ trợ. |
| `make install` | `uv sync --all-packages` | Đồng bộ thư viện cho tất cả các gói trong workspace. |
| `make run` | `uv run streamlit run src/main.py` | Khởi chạy ứng dụng. |
| `make upgrade` | `uv sync --upgrade` | Nâng cấp thư viện theo giới hạn trong `pyproject.toml` và cập nhật `uv.lock`. |

Kiểm tra các thay đổi và chạy thử ứng dụng sau khi nâng cấp thư viện, trước khi commit lockfile mới. Hiện chưa có bộ kiểm thử ứng dụng tự động.
